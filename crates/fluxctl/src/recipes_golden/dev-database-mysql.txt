Dev database

Steps
  1. start mysql in the local cluster
       fluxctl kube add mysql

Open it      mysql://root:dev@127.0.0.1:3306/app
Credentials
  url: mysql://root:dev@127.0.0.1:3306/app
  cli: mysql -h 127.0.0.1 -u root -pdev app
Backup       daily at 03:00
             fluxctl kube db-backup mysql "$HOME/db-backups/mysql-$(date +%F).sql"
Uninstall
  fluxctl kube remove mysql --delete-data
Note         The password is the development default shown in the connection string; the port is open on 127.0.0.1 only.
Note         Needs the local cluster: `fluxctl kube up` once.
