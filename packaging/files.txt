# What the Linux package contains. scripts/package-linux.sh builds exactly this and fails if anything required
# is missing; `scripts/package-linux.sh --check-manifest` validates this file without building (CI runs it).
#
# Columns (whitespace separated):  GROUP  KIND  SOURCE  DEST  MODE  [optional]
#
#   GROUP  core    what a node needs to run VMs (the default)
#          extras  not packaged yet: the Sentinel / runtime-intelligence daemons, the mesh agents, the containerd
#                  shim and the C loaders need libbpf at run time and a decision on a separate package
#   KIND   bin          SOURCE is <cargo package>/<binary>; built with cargo, stripped, copied to DEST
#          link         DEST is a symlink to SOURCE (relative to DEST's directory)
#          file         SOURCE is a path in the repository
#          bpf          SOURCE is an object scripts/build-ebpf.sh produces; built for the target architecture
#          guest        the static musl guest agent (scripts/build-guest-agent-static.sh); SOURCE is its file name
#          completions  SOURCE is a shell (bash|zsh|fish); generated by running the built fluxctl, so only on a
#                       native build (a cross-built binary cannot run here)
#   MODE   octal permissions
#   optional   a missing file is reported but does not fail the build (the guest agent needs the musl target,
#              completions need a native build). Everything else must be present.
#
# DEST is relative to the package root. The layout keeps bin/, share/config.example.toml and
# share/systemd/fluxvm.service where scripts/install.sh expects them; everything else is added next to them.
